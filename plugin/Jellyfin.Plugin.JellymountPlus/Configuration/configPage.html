JellymountPlus Theme

Cinematic dark theme for Jellyfin Web. Applying it writes an @import into Dashboard → Branding → Custom CSS — no file edits, works in Docker.

Optional extras

Extras add UI Jellyfin doesn't have (home hero, featured selector, expanded hover previews, NEW/JUST ADDED badges). They require a script tag — see the note below.

Extras need one script tag

Jellyfin can't inject scripts from a plugin alone. With extras enabled, add via JavaScript Injector or File Transformation:

<script defer src="/JellymountPlus/Assets/extras.js"></script>

Or paste the JS Injector snippet: var s=document.createElement('script');s.src='/JellymountPlus/Assets/extras.js';s.defer=true;document.head.appendChild(s);

After enabling extras, click Apply theme again so the full stylesheet is used.
